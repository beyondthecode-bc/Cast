# Cast Privacy Policy

Effective: July 28, 2026

The Mac App Store edition of Cast does not collect, transmit, track, sell, or
share personal data, and it does not make in-app network requests. Its support,
privacy, and translation links open the user's default browser; the destination
website's own policy applies after the user leaves Cast.

App preferences and the current randomizer state remain locally on the device.
Generated passwords are displayed for the user and are not persisted by Cast. If
the user chooses Copy, macOS places the value on the system clipboard.

Cast contains no advertising SDK, analytics SDK, account system, or
Cast-operated cloud service.

The Direct edition has the same local-data behavior. It may contact GitHub's
public releases API when checking for updates, but it sends no Cast settings,
randomizer state, or generated password. GitHub's own privacy policy governs
normal request and network metadata after that contact.

Support: https://github.com/beyondthecode-bc/Cast/issues
